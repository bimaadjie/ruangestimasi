# Anti-Slop Code Quality Skill

## Directives
1. Remove robotic narrator comments that restate the code line beneath them (e.g. `// Form fields`, `// UI states`, `// Button clicked`).
2. Maintain clean, focused files with modular component division.
3. Clean out unused, irrelevant platform configs and dead code.
4. Keep types and business logic cleanly separated from rendering concerns.
