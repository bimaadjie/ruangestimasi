# Anti-Slop UI Skill

## Directives
1. Remove generic purple/blue gradients and ungrounded glow effects.
2. Clean out unmotivated dot patterns, blueprint watermarks, and grid decorations (R-07).
3. Do not append decorative directional arrows to standalone buttons (R-08).
4. Never use sparkle/wand icons as lazy stand-ins for AI features; use clear descriptive labels and domain-appropriate icons (R-04).
5. Maintain crisp, intentional component contrast and clear visual hierarchy (R-25).
